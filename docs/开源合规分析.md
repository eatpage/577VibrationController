## 一、结论

**可以开源，而且很干净。**

- **你自己写的代码 100% 归你所有** —— 全部从零手写，没有任何一段是从其它开源项目复制来的。
- 依赖里**只有一个需要处理：PySide6（Qt）的 LGPLv3**。其余全是宽松许可证，随便用。
- 没有版权污点、没有需要署名才能规避的风险、没有需要向第三方付费的部分。

唯一要做的决策是：**你的代码用什么许可证**，以及**怎么打包分发**。见第四节。

## 四、PySide6 的 LGPLv3 到底要你做什么

这是整个开源里**唯一需要动脑**的地方，但也没那么可怕。

### LGPLv3 的三条核心义务

1. **声明**：告诉用户「本项目使用了 LGPLv3 授权的 Qt / PySide6」，并附带许可证全文。
2. **回馈修改**：如果你**修改过** PySide6 或 Qt 的源码，要公开你改的那部分。
   → **你没有改过**（用的是官方 wheel），**这一条自动满足，零义务。**
3. **可替换**：用户必须有能力把这份 Qt 库**换成他自己编译的版本**。

第 3 条就是打包方式的坑。

### 打包方式决定合规难度

| 打包方式 | Qt 库的形态 | LGPLv3 合规性 |
|---|---|---|
| **onedir（文件夹版）** | `_internal/PySide6/*.dll` 是**独立文件**，用户可直接替换 | ✅ 天然合规，无争议 |
| **onefile（单文件版）** | Qt DLL 被塞进 exe，运行时解包到临时目录 | ⚠️ 灰色地带 —— 广义上接近「静态捆绑」 |

**业界实践**：大量 PySide6 项目确实在发 onefile 单文件 exe，实际被追究的极少。但严谨来说，**要绝对干净就走 onedir**。

### 三条可选路线

| 路线 | 你的代码许可证 | PySide6 合规成本 | 适合谁 |
|---|---|---|---|
| **① 全项目 GPL-3.0** | GPL-3.0 | **零成本** —— GPL 比 LGPL 更严格，天然覆盖所有义务，不存在灰色地带 | 省心、社区友好、最推荐 |
| ② 你的代码 MIT + PySide6 单独走 LGPL 合规 | MIT | 需写 `THIRD_PARTY_NOTICES`、附 LGPL 全文、保证可替换（建议改发 onedir） | 希望别人能随意拿走你的代码 |
| ③ 你的代码 MIT，**只发源码不发 exe** | MIT | 最低 —— 不发二进制就不涉及 Qt 二进制的分发 | 不想管打包合规 |

## 五、另外五件必须处理的事

### 1. 品牌 —— 已清理，继续保持 ✅
`盖世小鸡 / GameSir / 启明星2 / T4n Lite` 已从代码和文档移除。开源版：
- **不要**用别人的商标做仓库名或 Topics
- README 里加一句「与任何硬件厂商无隶属或授权关系」

### 2. 波形命名的引用 —— 建议加免责声明
`core/waveforms.py` 注释里写了「参考 Lovense 的 pulse / wave / fireworks / earthquake」。
**参考命名和参数区间不侵权**（这些是行业通用描述词，且你复现的是概念而非代码）。但建议在 README 加一句「模式命名仅为行业通用描述，与相关厂商无关联」，避免误会。

### 3. ⚠️ 成人向内容 —— 这条请你亲自判断
项目含「玩具模式」「节律引导」分类，波形名有 `吸吮 / 抽送 / 逗弄`，以及 577 彩蛋。

**法律与平台规则层面**：
- GitHub《可接受使用政策》禁止的是**淫秽色情内容**。纯振动参数 + 文字描述**不构成**色情内容。
- 你**没有发布任何图片或视频**，这块是安全的。

**但风险点在于仓库的「门面」**：
- ❌ 仓库描述（Description）、Topics **不要写露骨词汇** —— 容易触发自动审核标记
- ✅ 建议在读我 README 顶部加一行：**「仅限成人使用 / 18+ only」**
- ✅ 波形名可以保留（技术参数而已），但描述文字避免生理露骨描写

### 4. 不要往仓库里传 exe
- GitHub 单文件上限 100MB，你的 57MB exe **能传但会让仓库体积暴涨**，每次 clone 都要拉 57MB。
- **正确做法：走 GitHub Releases** 上传 exe + zip，仓库里只放源码。

### 5. README 有个数据错误
README 写着「**55 种波形**」，实际是 **59 种**（加了玩具模式、节律引导、郊狼系波形和 577 彩蛋后没同步）。开源前要改。
